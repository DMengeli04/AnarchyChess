User Manual
There are two versions of the game, the command line version and the GUI version
Command line version:
Gui version:
    The code is compiled by visual studio, so I don't know if it can be compiled separetely.
    The executable is included in the github repo. It can be run on it's own, though it will
    likely be flagged as malware. The game plays like chess. Click on a piece and choose a spot
    to move it to. The game should only move pieces according to the rules of chess. Castling is
    done by clicking on the king and then the rook you want to castle with, given that you can castle.
    Pawn promotion opens a menu that lets you choose a piece. The buttons on the side reset the board and
    are used to choose the gamemode.
